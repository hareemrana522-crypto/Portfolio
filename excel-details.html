Automated Sales & Inventory System

End-to-End Data Process Automation (Excel VBA)

Project Overview

This is an end-to-end data process automation project built using Microsoft Excel VBA with direct Microsoft Outlook integration. It eliminates hours of manual copy-paste work by introducing clean, structured VBA automation.

📊 Phase 1: Sales Consolidation & Inventory Tracking

  • Automates multi-file data extraction (.xlsx) directly from specified local directories.
  • Performs instant de-duplication and data validation to flag invalid records.
  • Dynamically updates stock levels in real-time and triggers automatic LOW STOCK ALERT status.

📈 Phase 2: Automated KPI Reporting & Executive Email Dispatch

  • Auto-calculates key performance metrics (Total Revenue, Orders, Units Sold, and Average Order Value).
  • Formats an executive-ready MonthlyReport summary sheet and updates the dynamic dashboard visual chart.
  • Exports printable PDF reports and automatically launches Microsoft Outlook drafts with pre-filled bodies and attachments.

🖥️ Interactive UI

Built a dedicated UserForm (frmProduct) allowing seamless CRUD operations (Add, Update, Search, Delete) directly into the backend sheet.
