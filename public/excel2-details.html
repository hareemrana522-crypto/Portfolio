The Problem

Corporate finance departments lose hours each month manually cross-referencing bank statements against general ledger transactions. Traditional spreadsheet setups rely on fragile VLOOKUP or INDEX/MATCH formulas that fail whenever:

  • Vendor descriptions contain typos or abbreviations (e.g., AWS Cloud vs. Amazon Web Svcs).
  • Bank clearing dates differ from ledger recording dates.
  • Duplicate transactions or split payments skew line balances.

The Solution & System Architecture

I designed and developed an automated end-to-end reconciliation system that runs entirely inside Excel, providing software-level precision without requiring external SaaS subscriptions.

Dual-Source Ingestion Engine

Dynamic file-picker UserForm (frmImportFiles) imports inconsistent CSV/XLSX statements, validates schemas, and flags internal duplicates before processing.

Intelligent Multi-Pass Matching

  • Pass 1 (Deterministic): Exact pairing based on reference numbers, cash-flow type (Deposit/Withdrawal), and exact amounts.
  • Pass 2 (Fuzzy Logic & Date Tolerance): Employs a custom Levenshtein Distance algorithm to calculate string distance alongside a 2-day date tolerance window for ambiguous entries.
  • Pass 3 (Discrepancy Triage): Automatically separates items into Matched, Partially Matched, Unmatched Bank, and Unmatched Ledger.

Interactive Controller Review Portal

Custom UserForm (frmManualReview) displaying potential match pairs side-by-side, allowing financial controllers to confirm or decouple suggested records.

Audit Trail & Executive Reporting

Every action (import, manual verification, decoupling) is logged to an immutable audit trail with timestamps and user details. Outputs an executive-ready balance report with one-click PDF generation.

Key Technical Features

  • Levenshtein Distance Algorithm: Implemented natively in VBA for typo-tolerant matching without external dependencies.
  • Zero-Formula Backend: All matching logic executes via VBA arrays and memory dictionaries for instant processing of high row counts.
  • Audit-Compliant: Immutable logging ensures complete transparency for internal and external corporate auditors.
  • One-Click Delivery: Automates print layout, headers, and landscape PDF generation saved directly to local storage.
